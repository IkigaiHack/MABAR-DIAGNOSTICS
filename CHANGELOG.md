# MABAR DIAGNOSTICS — historia zmian

## 1.0.2
- Dodano panel sprawdzania aktualizacji z manifestu JSON.
- Dodano pobieranie nowej wersji HTML.
- Zachowano lokalne przechowywanie danych warsztatu.
- Dodano przypomnienie o kopii zapasowej przed aktualizacją.

## Ważne
Wersja HTML pobiera aktualizację na żądanie użytkownika. Nie nadpisuje po cichu otwartego pliku. Automatyczne pobieranie z prywatnego repozytorium wymaga bezpiecznej autoryzacji lub osobnego publicznego kanału wydań.

## 1.0.3 — test aktualizatora
- Podniesiono numer wersji aplikacji do 1.0.3.
- Dodano widoczne oznaczenie kompilacji testowej.
- Przygotowano wydanie do sprawdzenia pobierania aktualizacji z publicznego GitHuba.

## 1.0.4 — automatyczne aktualizacje
- Domyślny adres manifestu GitHub jest wbudowany w aplikację.
- Aktualizator automatycznie sprawdza wersję po otwarciu zakładki Aktualizacje.
- Nie trzeba ręcznie wklejać adresu manifestu.
